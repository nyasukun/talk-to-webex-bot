The PNG is the generated source; `scripts/build-icon.sh` uses macOS `sips` and `iconutil` to create the multi-resolution ICNS. `scripts/build.sh` installs it in the application bundle. ## Generation prompt

Use case: logo-brand. Asset type: production macOS app icon for 'Talk to Webex bot', a local voice assistant that listens to a spoken command and sends it to a chat bot. Create one polished 1024 x 1024 square icon. Subject: a single bold speech bubble whose center contains three simple vertical rounded waveform bars, immediately legible at small sizes. A tactile but restrained macOS style with gently raised shapes, luminous turquoise and emerald on a deep blue-green rounded-square tile. Centered composition with generous padding, large simple silhouette, subtle soft highlights, crisp smooth edges. Transparent canvas outside the rounded tile, actual alpha transparency, no white background. No lettering, no words, no watermark, no additional badges, no product mockup, no official Webex or Cisco logo. Deliver only the icon.
